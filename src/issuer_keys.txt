# MCPG licence issuer public keys. APPEND ONLY.
#
# The only keys a release build trusts to sign a licence. Every record is
# permanent: a key is never edited or deleted, because an older release still
# ships it and the tokens it signed are still in the field. A key that must stop
# being trusted gets a `revoke` record appended below it; releases from then on
# refuse every token it signed. `trust::tests::the_key_file_is_append_only`
# holds the file to that rule.
#
# Records, one per line, fields separated by whitespace:
#
#   key    <kid> <role> <environment> <public-key> <added>
#   revoke <kid> <revoked-on>
#
#   kid          RFC 7638 JWK thumbprint of the key (SHA-256, base64url, no
#                padding); `mcpg-license keygen` prints it.
#   role         self_host  signs self-host licences (`mcpg-license issue`)
#                cloud      signs the licences the mcpg.cloud federation issues
#                platform   signs no licence: the delivery proofs an mcpg.cloud
#                           control plane sends with each licence it delivers
#   environment  production admits any licence
#                staging    admits only a licence that marks non_production
#                           (a staging platform key vouches only for a
#                           delivery of such a licence, or of none)
#   public-key   the raw 32-byte Ed25519 public key, base64url without padding
#                (the JWK `x` member)
#   added, revoked-on   YYYY-MM-DD
#
# MCPG's licence key ceremony produces these records: `mcpg-license keygen
# --role <role> --environment <environment>` prints the record of each new key.
